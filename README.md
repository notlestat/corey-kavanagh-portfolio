# Corey Kavanagh portfolio preview

A local, unpublished working version of the Paper portfolio direction. The opening type sequence follows page scroll. In the work area, wheel scrolling moves an endless image strip only while the pointer is over it. Elsewhere, the page scrolls normally. On smaller screens and with reduced motion enabled, the strip becomes swipeable.

## Run locally

```sh
npm install
npm run dev
```

Open the local address printed by Vite. Run `npm run build` to check the production build.
